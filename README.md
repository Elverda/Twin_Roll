## 🎯 Tentang Proyek

**Twin Roll** adalah aplikasi multi-platform yang mengintegrasikan kekuatan Dart untuk UI yang responsif dengan performa tinggi C++ untuk komputasi native. Proyek ini menggabungkan yang terbaik dari kedua dunia untuk memberikan pengalaman pengguna yang optimal dengan performa yang superior.

### Keunggulan Proyek

- 🚀 **Performa Tinggi**: Memanfaatkan C++ untuk operasi yang intensif
- 🎨 **UI Modern**: Dibangun dengan Dart dan Flutter framework
- 🔄 **Cross-Platform**: Kompatibel dengan berbagai platform
- 🛠️ **Build System Modern**: Menggunakan CMake untuk manajemen build

## ✨ Fitur

- Integrasi seamless antara Dart dan C++
- Native performance untuk operasi kompleks
- Antarmuka pengguna yang responsif dan intuitif
- Dukungan multi-platform
- Mudah diperluas dan dikembangkan

### Frontend & Framework
- **Dart** (66.1%) - Bahasa pemrograman utama untuk aplikasi
